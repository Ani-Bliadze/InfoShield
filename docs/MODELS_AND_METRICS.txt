InfoShield — Models, Confidence, Languages & Metrics
====================================================

PIPELINE (per post)
  1. Hate detector  (local, multilingual)        -> hate_confidence
  2. Manipulation detector (local, multilingual)  -> manipulation_confidence
  3. If either flags -> Gemini ANALYSIS explains the techniques (gemini-3.5-flash)
  4. Gemini VERIFIER double-checks the analysis (gemini-3.1-pro-preview); if it is not
     relevant/accurate, the flag is overturned as a false positive.
  (Both LLM steps fall back to Groq automatically if Gemini is unavailable.)

HOW CONFIDENCE IS DETERMINED
  - Hate confidence = softmax probability of the OFFENSIVE/HATE class from the XLM-T
    head (0.0-1.0). Flagged when >= 0.40.
  - Manipulation confidence = the strongest single *concrete technique* probability
    (max of the sigmoid outputs over the persuasion techniques; structural taxonomy
    nodes like ROOT/Logos/Ethos/Pathos are excluded so a parent category doesn't fire
    on everything). Flagged when >= 0.50 (recall-first; the verifier removes false
    positives).
  - The number shown on a post = the score of whichever detector flagged it.
  - "high_confidence" when that score >= 0.80.
  - Overlay wording:  >= 0.80 -> "Detected with NN% confidence",
                      else    -> "May contain indicators (NN% confidence)".

LANGUAGES (now multilingual; was English-only)
  - Hate model (Andrazp/multilingual-hate-speech-robacofi, XLM-T backbone): fine-tuned
    and validated on Arabic, Croatian, English, German, Slovenian; the XLM-T backbone
    was pretrained on tweets in 30+ languages.
  - Manipulation model (nishan-chatterjee/multilingual-persuasion-detection-from-text,
    mBART backbone): multilingual persuasion-technique detection over the SemEval-2023
    taxonomy; mBART covers ~50 languages. Russian detection verified on our demo feed.
  - Gemini analyzer + verifier (Groq fallback): multilingual.
  HONEST SCOPE: this is a "multilingual backbone with VALIDATED support for the
  evaluated languages," NOT a guaranteed "100+ language" detector. Confidence/thresholds
  are trustworthy in evaluated languages and should be recalibrated per deployment
  (per language / language family is ideal). Zero-shot transfer to unseen languages is
  not assumed; the LLM verifier is the precision backstop.

MODEL METRICS / PROVENANCE (strong, published multilingual models)
  Hate: Andrazp/multilingual-hate-speech-robacofi
    - XLM-T (multilingual Twitter/X RoBERTa), binary offensive/hate.
    - Reported F1 by language: 0.72 (Croatian) to 0.87 (Arabic) across the 5 fine-tuned
      languages.
  Manipulation: nishan-chatterjee/multilingual-persuasion-detection-from-text
    - mBART, multi-label persuasion-technique detection built on the SemEval-2023 Task 3
      taxonomy (the multilingual persuasion benchmark; 9 languages, 23 techniques).
    - We use it as a binary gate via the max concrete-technique probability; threshold
      0.50 with the verifier as the precision backstop (re-tune per docs/EVALUATION.md).
  English fallbacks (load only if a multilingual model is unavailable):
    - Hate: cardiffnlp/twitter-roberta-base-hate-latest (acc 0.877, macro-F1 0.753).
    - Manipulation: synapti/nci-social-classifier-v3 (F1-micro 0.796, F1-macro 0.551).

WHY THESE MODELS (per the multilingual research review)
  - Keep the architecture (fast local detector first, LLM explainer + verifier second);
    swap the English-only detectors for multilingual backbones (XLM-T for hate, mBART
    persuasion for manipulation) so non-English posts are flagged NATIVELY -- no
    translation step.
  - Both run locally (fast, free, private). The manipulation signal on short social
    posts is weaker than on news text, so it is tuned recall-first and the LLM verifier
    prunes the false positives. Evaluate detector-alone AND detector+verifier
    (docs/EVALUATION.md, backend/scripts/evaluate.py).
